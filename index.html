Kindle's Enhanced Typesetting does not render SVG, so figures are embedded as high-resolution raster, sized by CSS.)

Which colors survive is decided by "Body text black for contrast" in the common settings, the same rule the DOCX conversion uses: on a white page a color below 4.5:1, or a grey, is not a color choice but a screen theme. Turn print mode on first so the colors read are the ones meant for paper.)

(The HTML's own <style> is not carried into the EPUB — screen colors break on a device — so without this a callout collapses into plain body text. No background color: E Ink turns it into a grey slab, and in dark mode text with no color of its own becomes unreadable on it.)
